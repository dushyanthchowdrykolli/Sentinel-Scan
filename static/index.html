What gets scanned

  • Security HTTP headers (CSP, HSTS, X-Frame-Options …)
  • Cookie flags (Secure, HttpOnly, SameSite)
  • TLS certificate and protocol (HTTPS targets)
  • Server and technology banner disclosure
  • Common exposed paths and directory listing
  • CORS misconfiguration (wildcard / reflected origin)
  • HTML forms without anti-CSRF tokens
  • Reflected XSS probe (harmless marker injection)
  • SQL injection probe (error-based, read-only)
